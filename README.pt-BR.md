# helium-linux — build de performance e baixa memória

Fork do empacotamento Linux do Helium com PGO, ThinLTO e política opcional de baixo uso de memória.

## Como compilar

```bash
./scripts/docker-build.sh --performance
```

O build completo exige aproximadamente 100 GB livres. Consulte `README.md` para detalhes técnicos.
